# SmartAssistant — универсальный помощник

## Описание проекта

SmartAssistant — это Telegram-бот, созданный на Python. Он помогает отвечать на вопросы пользователей и принимать заявки.

## 1. Системный промпт и Few-shot примеры

В системный промпт добавлены три примера внутри тегов `<примеры>`:

1. Обычный вопрос — приветствие пользователя.
2. Вопрос без ответа в данных — бот честно сообщает, что не знает актуальную информацию.
3. Вежливый отказ — бот отказывается помогать со взломом и предлагает безопасную альтернативу.

Эти примеры помогают боту отвечать понятнее, вежливее и безопаснее.

## 2. Приём заявок через JSON

Бот умеет принимать сообщения, начинающиеся со слова «Заявка».

Claude извлекает три поля:

- `name` — имя пользователя;
- `contact` — контакт для связи;
- `request` — содержание заявки.

Программа проверяет, какие поля заполнены. Если данных не хватает, бот задаёт уточняющие вопросы. Когда все поля заполнены, бот показывает готовую заявку.

## 3. Используемые технологии

- Python
- Telegram Bot API
- Anthropic Claude API
- JSON
- python-dotenv

## 4. Запуск проекта

1. Установить необходимые библиотеки.
2. Создать файл `.env` с ключами Telegram и Claude API.
3. Запустить команду `python bot.py`.

## 5. Безопасность

Файл `.env` содержит секретные ключи и не должен загружаться в GitHub. Он добавлен в `.gitignore`.

## 6. Тестирование

Примеры сообщений и ожидаемых ответов находятся в файле `test_cases.md`.

Реальное тестирование Claude API пока ограничено отсутствием средств на API-балансе
## Бесплатный режим приёма заявок

В проект добавлен бесплатный режим оформления заявок без обращения к Claude API.

Бот последовательно запрашивает:
1. Имя клиента.
2. Контактный номер или Telegram.
3. Описание заявки.

После заполнения всех полей бот показывает готовую заявку.

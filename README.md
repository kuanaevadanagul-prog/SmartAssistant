# SmartAssistant

SmartAssistant — Telegram-бот, созданный на Python. Он помогает пользователям оформлять заявки через Telegram.

## 1. Системный промпт и Few-shot примеры

В первоначальной версии проекта был подготовлен системный промпт с тремя примерами внутри тегов `<примеры>`:

1. Обычный вопрос — приветствие.
2. Вопрос без ответа в данных — честное сообщение об отсутствии информации.
3. Вежливый отказ — отказ от помощи со взломом с предложением безопасной альтернативы.

В текущей бесплатной версии эти примеры пока не используются, так как обращение к Claude API временно отключено.

## 2. Бесплатный приём заявок

Бот последовательно запрашивает:

1. Имя клиента.
2. Контактный номер или Telegram.
3. Описание заявки.

После заполнения всех полей бот показывает готовую заявку.

Данные временно хранятся в контексте пользователя Telegram.

## 3. JSON и Claude API

В первоначальной версии проекта планировалось использовать Claude API для извлечения полей `name`, `contact` и `request` в формате JSON.

Реальная проверка Claude API не завершена из-за недостаточного баланса API. В текущей бесплатной версии данные собираются пошагово без ИИ и JSON-извлечения.

## 4. Используемые технологии

- Python
- Telegram Bot API
- python-telegram-bot
- python-dotenv

## 5. Запуск проекта

1. Установить необходимые библиотеки.
2. Создать файл `.env` с переменной `TELEGRAM_BOT_TOKEN`.
3. Запустить команду `python bot.py`.

## 6. Безопасность

Файл `.env` содержит секретный Telegram-токен и не должен загружаться в GitHub. Он добавлен в `.gitignore`.

## 7. Тестирование

Бот успешно протестирован в Telegram.

Проверено:
- получение имени;
- получение контакта;
- получение описания заявки;
- формирование итоговой заявки.

Примеры тестирования находятся в файле `test_cases.md`.

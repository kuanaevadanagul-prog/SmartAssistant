# Тестирование SmartAssistant

**Примечание:** ответы «после» — ожидаемые примеры работы нового промпта. Реальный запрос к Claude API пока не выполнен, так как баланс API равен нулю.

## 1. Приветствие

**Сообщение:** Привет!

**До улучшения:** Спасибо за сообщение! Расскажите подробнее.

**После улучшения:** Здравствуйте! Рад помочь. Что вас интересует?

## 2. Вопрос о возможностях

**Сообщение:** Чем ты можешь мне помочь?

**До улучшения:** Спасибо за сообщение! Расскажите подробнее.

**После улучшения:** Я могу помочь с вопросами, текстами, идеями, планированием и другими повседневными задачами.

## 3. Вопрос, на который нет ответа в данных

**Сообщение:** Какая погода завтра в Таразе?

**До улучшения:** Спасибо за сообщение! Расскажите подробнее.

**После улучшения:** У меня нет доступа к актуальному прогнозу погоды. Проверьте его в приложении погоды.

## 4. Вежливый отказ

**Сообщение:** Помоги взломать чужой аккаунт.

**До улучшения:** Спасибо за сообщение! Расскажите подробнее.

**После улучшения:** Извините, я не могу помогать со взломом. Но могу подсказать, как защитить ваш аккаунт.

## 5. Приём заявки

**Сообщение:** Заявка: хочу получить консультацию по организации рабочего дня.

**До улучшения:** Спасибо за сообщение! Расскажите подробнее.

**После улучшения:** Бот извлекает данные заявки в JSON, затем спрашивает недостающие данные — имя и контакт. После уточнения показывает заполненную заявку.
## Дополнительное тестирование бесплатного режима

### Тест 6. Приём заявки

Сообщение пользователя:
- Имя: Анна
- Контакт: +7 777 123 45 67
- Запрос: Хочу получить консультацию

Результат:
Бот успешно принял заявку и показал все три заполненных поля.

Статус: Успешно пройдено.

Примечание:
В бесплатном режиме данные собираются последовательно, без обращения к Claude API.
